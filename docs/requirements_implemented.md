## 5. データフロー

### 5.1 プロファイル選択フロー
```
User Action (Connections画面で"Connect"クリック)
    ↓
profileStore.selectProfile(name)
    ↓
api.getClusterInfo(profileName) ← Tauri Command
    ↓
[Rust] es_client.get_cluster_info()
    ↓
[Elasticsearch] GET /_cluster/health & GET /
    ↓
[Rust] ClusterInfo返却
    ↓
[React] profileStore更新（currentProfile, clusterInfo）
    ↓
[React] Header/Dashboardに反映
```

### 5.2 データ抽出フロー
```
User Action (Extract画面で"データを抽出"クリック)
    ↓
api.extractAndStoreData(profile, index, query, tableName)
    ↓
[Rust] es_client.search() → ESからデータ取得
    ↓
[Rust] duckdb.create_data_table() → テーブル自動生成
    ↓
[Rust] duckdb.insert_data() → データ挿入
    ↓
[Rust] duckdb.save_extraction_job() → 履歴保存
    ↓
[React] 結果メッセージ表示（トースト通知）
```
